PART 1: DESIGN SYSTEM
BRAND POSITIONING
Quiet-luxury real estate brand for the DMV. Confident, warm, precise - closer to a private advisory firm than a typical agent site.

COLOR PALETTE

Primary Accent - Butter Yellow - Hex F3DFA2
Usage: Signature color, profile ring, dividers, hover states

Secondary Accent - Deep Butter - Hex E4C878
Usage: Buttons, active nav state

Base Dark - Charcoal Gray - Hex 1C1C1E
Usage: Primary background, nav, footer

Base Light - Warm Off-White - Hex F7F5F0
Usage: Alternating section backgrounds

Text Primary - Soft White - Hex EDEDED
Usage: Body copy on dark backgrounds

Text Secondary - Stone Gray - Hex 8A8A8E
Usage: Captions, metadata, license text

Border/Divider - Hairline Gray - Hex 2E2E30
Usage: 1px rules and dividers

Signature color recommendation: Lock butter yellow in as Careme's signature across every platform - the website, email signature, link.me profile ring, business cards. Use it sparingly - profile photo ring, call-to-action buttons, numbered list markers, hover underlines. Charcoal carries the visual weight; butter yellow is the accent.

TYPOGRAPHY

Display and Headlines: Serif font - Fraunces or Canela. Sentence case, generous letter spacing, never all-caps for full headlines.

Body Text: Inter or Sohne, light or regular weight.

Navigation, Labels, Numbered Markers: Small caps or tabular numerals, Butter Yellow color, slightly increased letter spacing.

LOGO LOCKUP
Top line: THE ONE STREET COMPANY (wordmark, Butter Yellow or Soft White)
Below it, smaller: SAMSON PROPERTIES (brokerage logo)

Placement: header (small, top) and footer (larger, centered). Request official logo files in SVG or EPS format plus exact brand spacing rules from Samson Properties before build.

IMAGERY STYLE
Full-bleed cinematic property photography, no stock imagery. Portraits should use a charcoal backdrop with soft single-source light, optional butter-yellow rim light. One hero image per section, generous negative space.

LAYOUT PRINCIPLES
Max content width: 1200px
Section vertical spacing: 120 to 160px on desktop
12-column grid, 24px gutter
Numbered-list service and highlight sections (01 through 04 style) used consistently across About, Services, and Resources sections
Micro-interactions only: fade-up on scroll, underline draw on hover, counter animation on stats - nothing bouncy or playful

BUTTONS
Primary: Butter Yellow fill, Charcoal text, max 4px corner radius
Secondary: Transparent background, 1px Butter Yellow border and text
Hover state: invert fill and text colors, 200ms transition

ICONOGRAPHY
Line icons only, 1.5px stroke weight, Butter Yellow or Stone Gray color only - never filled or solid icons

SECTION 2: ZILLOW LISTINGS INTEGRATION

Critical Constraint:
Zillow discontinued its public listings API in 2021. There is no official API to pull live MLS listings from Zillow into a third-party site. Scraping Zillow violates their Terms of Service and is not viable for a licensed agent's professional website.

OPTION A (Recommended Long-Term): IDX Feed via Bright MLS
Careme's MLS is Bright MLS, covering the DC/MD/VA region. IDX providers pull real-time listing data directly from Bright MLS, not Zillow - fully compliant and auto-updating.

Recommended IDX Providers:
iHomefinder - easiest integration for WordPress or custom sites
Showcase IDX - strong design customization
Realtyna / WPL - flexible, developer-friendly
Real Geeks - includes CRM plus lead capture bundled

Implementation Flow:

Careme, via her broker Samson Properties, requests Bright MLS IDX credentials.
Sign up with chosen IDX provider, connect Bright MLS credentials.
Provider issues an embed script or plugin.
Style the output using the provider's CSS override options to match the brand (Butter Yellow and Charcoal theme).
Example embed code (exact snippet provided by IDX vendor):

<div id="idx-listings-widget" data-mlsid="BRIGHT_MLS_ID"></div> <script src="https://[idx-provider].com/widgets/listings.js" async></script>
Estimated Cost: $40 to $150 per month depending on provider and features.

OPTION B (Launch-Ready, Zero Cost): Zillow Profile Link-Out
Simple branded button linking to Careme's official Zillow agent profile and search page.

Example code:
<a href="https://www.zillow.com/profile/[careme-profile-slug]" target="_blank" class="btn-secondary">
Search Homes on Zillow
</a>

This fully satisfies the original request with zero technical risk or ongoing cost.

OPTION C (Launch-Ready): Manually Curated Featured Listings
Recreates the "pop-up beautiful house cards" visual effect using Careme's own listing photos and data - fully owned content, no scraping involved.

SECTION 3: MORTGAGE AND PROPERTY CALCULATOR

Overview:
A client-side calculator requiring no backend. Standard trust-building tool on premium real estate websites.

Placement:
Standalone "Estimate Your Payment" module on the Listings page, directly below Featured Listings. Styled as a Charcoal card with Butter Yellow accent on output numbers.

Input Fields:
Home Price - Number field, dollar amount - Default $600,000
Down Payment - Number or percentage toggle - Default 20%
Loan Term - Dropdown - Options: 15, 20, or 30 years
Interest Rate - Number field, percentage - Auto-suggested current average, editable
Property Tax (annual) - Number field - Optional, estimated at 1.1% of home price
Home Insurance (annual) - Number field - Optional, estimated at $1,200
HOA (monthly) - Number field - Optional

Output Display:
Estimated Monthly Payment - large, Butter Yellow colored number
Breakdown showing: Principal and Interest / Taxes / Insurance / HOA
Optional: donut chart visualizing the payment breakdown

Calculation Logic (JavaScript function):

function calculateMortgage({
homePrice,
downPaymentPercent,
loanTermYears,
annualInterestRate,
annualPropertyTax = 0,
annualInsurance = 0,
monthlyHOA = 0
}) {
const downPayment = homePrice * (downPaymentPercent / 100);
const loanAmount = homePrice - downPayment;
const monthlyRate = (annualInterestRate / 100) / 12;
const numPayments = loanTermYears * 12;

const monthlyPI =
monthlyRate === 0
? loanAmount / numPayments
: (loanAmount * monthlyRate * Math.pow(1 + monthlyRate, numPayments)) /
(Math.pow(1 + monthlyRate, numPayments) - 1);

const monthlyTax = annualPropertyTax / 12;
const monthlyInsurance = annualInsurance / 12;

const totalMonthly = monthlyPI + monthlyTax + monthlyInsurance + monthlyHOA;

return {
loanAmount: loanAmount.toFixed(2),
monthlyPI: monthlyPI.toFixed(2),
monthlyTax: monthlyTax.toFixed(2),
monthlyInsurance: monthlyInsurance.toFixed(2),
monthlyHOA: monthlyHOA.toFixed(2),
totalMonthly: totalMonthly.toFixed(2)
};
}

UI Behavior:
Live-updates output on every input change, no submit button needed. Sliders preferred over raw number fields for Down Payment percentage and Interest Rate - feels more premium and interactive. On mobile, stack inputs vertically and keep the output number sticky/visible while scrolling.

Build Options:
Custom-built (React/Vue component) - Recommended. Fully brand-matched, no third-party branding, no monthly cost, but requires developer time.
Third-party widget (Bankrate, MortgageCalculator.org) - Faster to implement but carries external branding, harder to match the Butter Yellow/Charcoal theme. Not recommended for a premium-positioned site.

Lead-Capture Tie-In (Phase 2, optional):
Add an optional field at the bottom of the calculator results: "Want a personalized pre-approval estimate? Schedule a Consultation" - links directly to the Google Calendar booking flow. Turns a passive tool into a lead-generation touchpoint.
